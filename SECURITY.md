# Security Policy

This repository is a distribution surface for Frog CLI release binaries and channel pointers.

Do not publish a security-sensitive issue about a released binary in a public issue before it is triaged. Use GitHub Private Vulnerability Reporting / Security Advisories for this repository when available:

https://github.com/putao520/frog-cli-cdn/security/advisories/new

Include the affected release/version, platform/architecture, reproduction steps, expected impact, and any relevant hashes or artifact names.

Non-security download, release, checksum, or channel-pointer problems may be reported through normal GitHub Issues.
